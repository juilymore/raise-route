## 5. Troubleshooting
| Symptom | Likely cause → fix |
|---|---|
| Vercel deploy error "Hobby accounts are limited to daily cron jobs" | Cron expression runs >1×/day. Keep `0 3 * * 1,4` (Mon+Thu). |
| Function timeout / `maxDuration` rejected | Set 60 and `PIPELINE_TIME_BUDGET_MS=50000`; chunking resumes automatically. |
| Gemini 429 / "quota" on the first run | Free-tier limits are tiny. Enable billing, or lower `LLM_MAX_CALLS_PER_RUN`, or switch primary model. |
| Grounded search returns nothing / not allowed | Grounding isn't on the free tier for Gemini 3.x → use `gemini-2.5-flash` for that channel or disable `GEMINI_ENABLE_GROUNDING`. |
| 42501 "permission denied for table" | Grants are explicit. Migrations include them; for new tables add `0003_*.sql` with grants. |
| First request after idle is slow | Neon scales to zero; the first query wakes it (about a second). Normal. |
| Resend 403 "can only send testing emails to your own address" | Without a verified domain, send **to your signup email only** (`DIGEST_RECIPIENT`). |
| Everything shows PARTIAL | Source channels failing (see `/runs/<id>` → source health). That's the honest state — fix sources, don't hide it. |
